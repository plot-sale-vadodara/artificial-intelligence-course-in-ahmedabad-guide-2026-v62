For instance, consider this simple Python snippet for a machine learning model using Scikit-learn:

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

# Load dataset
data = load_iris()
X = data.data
y = data.target

# Split data
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Initialize classifier
clf = RandomForestClassifier(n_estimators=100)

# Train model
clf.fit(X_train, y_train)

# Predict
predictions = clf.predict(X_test)


This code illustrates a fundamental approach to building a machine learning model, which is just a small glimpse of what you can learn in an AI course.
